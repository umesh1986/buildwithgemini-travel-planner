# My agent: travel-planner
One-liner: A conversational agent that helps travelers assemble tailored trip itineraries with a catalog of destinations and illustrated highlights.

Tool coverage:
- Memory: User travel style, budget preferences, dietary restrictions, and past destinations visited
- Tools: Destination lookup, weather forecast check, and itinerary assembly
- Catalog/UI: Day-by-day itinerary cards, destination highlights, and packing checklist tables
- Image gen: Illustrated destination postcards and landmark scenes for each itinerary stop
- Sandbox: Trip budget calculation and multi-currency expense estimation

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for budget calculations, a live external API like Maps
